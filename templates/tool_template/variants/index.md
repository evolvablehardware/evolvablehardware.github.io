# Tutorials

This includes a series of pages for all slight variants of this tool. They should use largely the same documentation or follow very similar operating principles. This page documents what the specific variants of the tool are, and relates them back to the main documentation that is specified elsewhere. 

These variant pages should be formatted consistently across all variants for a specific tool, but otherwise should be designed to fit the need.

These pages only contain information relevant to identify the variant and note any differences from the common case, potentially linking to relevant documentation.

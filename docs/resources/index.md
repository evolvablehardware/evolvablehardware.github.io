# Resources

What is the **resources** tab for and how is it different from **publications**?

- I think that there should be one place to look for all related papers/books to learn about this topic.
    - There may be value in having a pre-publication section for random experiments, ideas for papers, and papers in review that aren't put front and center.
    - I think that there should be some separation between what this group produces and what is externally produced but useful for this project, but I feel that that separation is small.
- I think that resources and publications should be combined into one section, noting all books, papers, and "memos/opinions" that come from this project or that contribute to building knowledge for these projects.
- I think that we remove **publications** from a top-level title, and instead just use Resources with the following structure:


### 9. Software Setup

After the hardware is assembled, you are ready to install the Bitstream Evolution software stack and run the example experiments. Clone the toolkit from GitHub:

```
https://github.com/evolvablehardware/BitstreamEvolution
```
Refer to the repository’s README for environment setup, dependencies, and experiment-specific scripts.

Please note that the software stack is currently designed for the iCEstick FPGA development board. If you are using a different board, such as the pico2-ice, please refer to the [pico2-ice port of Bitstream Evolution](./bitstream_evolution_pico2-ice/index.md) for the appropriate software setup instructions and repository.

This software requires a Linux of MacOS environment with Python 3.8+ and the necessary FPGA toolchains installed. The README provides detailed instructions for setting up the development environment, installing dependencies, and running the example evolutionary experiments on the iCEstick board.

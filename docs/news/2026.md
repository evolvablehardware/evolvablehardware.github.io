### New Development Board integrated with Bitstream Evolution!
`March 2nd, 2026`

We have successfully integrated a new development board with the Bitstream Evolution technology stack. This board offers enhanced capabilities and will allow us to conduct more complex experiments in evolvable hardware. The pico2-ice board is now fully supported, and we look forward to sharing results from experiments conducted on this platform in the near future. For more information about the pico2-ice board, please visit [pico2-ice developer website](https://pico2-ice.tinyvision.ai/). To start using the pico2-ice board with Bitstream Evolution, the new repository can be found [here](https://github.com/evolvablehardware/BitstreamEvolutionPico2ice)

# Branding

This folder consists of all branding related to Evolvable Hardware. 

## Editing These Files
To Edit anything, make the edits in the `Inkscape_Logo_Editor.svg` file in Inkscape.
(Please Name the items you create and order and group the layers well.)

## Purpose of Files
- `logo.png`
    - This file is a high-resolution image of the current EHW logo.
    - This is the image that will be displayed prominently on the website or in various documents relating to EHW
- `favicon.png`
    - This is a low-resolution version of the logo.png meant to be used for browser icons.

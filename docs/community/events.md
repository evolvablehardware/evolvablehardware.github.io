The premier international conference in evolutionary computation, featuring dedicated sessions on evolvable hardware.

**Our Community Participation:**
- **Active paper submissions** from community members

- **Workshop organization** on practical EHW

## Community Workshops and Tutorials

### "Getting Started with Evolvable Hardware"
**Quarterly Beginner Workshops**

**Comprehensive tutorial covering:**
- Historical background and motivation  
- Hardware platform setup (iCE40 + Arduino)
- Software installation and configuration
- Running first variance maximization experiment
- Understanding results and next steps

**Format:** 4-hour hands-on session via video conference
**Prerequisites:** Basic programming knowledge helpful
**Materials provided:** Setup guides, code examples, troubleshooting resources

### "Advanced Evolution Techniques"
**Semi-Annual Technical Workshop**

**Topics include:**
- Custom fitness function development
- Multi-objective optimization strategies  
- Hardware platform customization
- Data analysis and visualization
- Research methodology and experimental design

### Hardware Build Sessions
**As Needed - Community Driven**

Collaborative sessions for:

- **Custom PCB design** for specialized experiments
- **Measurement system** setup and calibration
- **Multi-FPGA platforms** for distributed evolution
- **Testing and validation** of new hardware
